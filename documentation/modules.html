Modules & Scope

Soleil keeps Lua's module system: a module is a file that returns a table, and its public surface can be fully typed.

Lexical scope

local declares block-scoped variables. Inner blocks can shadow outer names, and do...end limits a declaration's lifetime.

scope.sol content_copy 
local orbit = "inner"

do
    local orbit = "scoped to this block"
    print(orbit) -- scoped to this block
end

print(orbit) -- inner

Defining a module

A module file builds a table and returns it. Annotate the public functions so callers are checked too.

star.sol content_copy 
local star = {}

function star.greet(name : string) : string
    return "Hello from " .. name
end

return star

Requiring modules

require loads a module once and caches it for every future caller, exactly like Lua.

main.sol content_copy 
local star = require("star")

print(star.greet("Sol")) -- Hello from Sol

Declaration headers

For existing Lua libraries, Soleil accepts .hds declaration files: signatures with empty bodies that the checker trusts. This is how the string library itself is typed — no runtime cost, no rewiring.

libstring.hds content_copy 
function string.sub(s : string, i : number, j : number?) : string end
function string.rep(s : string, n : number) : string end
