Syntax

Soleil keeps the surface syntax of Lua 5.1 and layers a static type system on top. If you know Lua, you already know how to read Soleil.

Comments and statements

Statements are separated by newlines or semicolons. Comments start with a double dash, and long blocks use Lua's [[ ... ]] form.

comments.sol content_copy 
-- a line comment
--[[ a long
     comment ]]
local greeting = "hello"; print(greeting)

Variables

Variables are declared with local. Type annotations are optional — when present they are written with a colon and spaces, name : type. Without one, the type is inferred from the initializer.

variables.sol content_copy 
local sun = "Sol"              -- inferred as string
local temperature = 5778       -- inferred as number
local visible : boolean = true -- explicit annotation
local badge                    -- declared, assigned later

Control flow

Soleil uses Lua's block keywords: if / then / elseif / else / end, while, repeat / until, numeric and generic for, plus break.

control.sol content_copy 
if temperature > 5000 then
    print("blue white")
elseif temperature > 3000 then
    print("yellow")
else
    print("red dwarf")
end

for i = 1, 10, 2 do
    print(i)
end

local bodies = { "Mercury", "Venus", "Earth" }
for index, name in ipairs(bodies) do
    print(index, name)
end

while true do
    break
end

Escaped identifiers

Need a variable named after a keyword — say, when porting Lua code that uses class as a table name? Wrap it in backticks.

escapes.sol content_copy 
local `class` = 5
`class` = 6
print(`class`)  -- 6

Operators

All Lua 5.1 operators are available, plus Soleil's null operators (?., ?:, !! — see Null Operators). They are strict about types:

  • Arithmetic: + - * / % ^ — numbers on both sides
  • Comparison: == ~= < <= > >= — like-typed operands
  • Logic: and or not
  • Concatenation: .. requires strings — numbers do not coerce; spell it out: tostring(42) .. "!"
  • Length: #; call sugar: f{...} ≡ f({...}), f"str" ≡ f("str")
concat.sol content_copy 
local n = 42
print(tostring(n) .. "!")  -- 42!
-- print(n .. "!")         -- error: concat requires strings

Numerals

Every Lua 5.1 spelling is grammar: decimal, exponent, hex, and trailing-dot. There are no 5.4 additions — hex floats are not grammar, and inf/nan are not literals (they are ordinary identifiers in Lua 5.1).

numerals.sol content_copy 
local a = 42
local b = 1.5e-3
local c = 0xFF
local d = .5
local e = 10e500  -- keeps its raw text end-to-end, never a printed inf
