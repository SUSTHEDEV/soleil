Functions

Functions are values in Soleil, just like Lua — with checked signatures and explicit returns.

Declaring functions

Return types are annotated after the argument list, comma-separated for multiples. Implicit nil is the rule: a function that declares no return types returns nil and may not return values — return 42 in a rets-less function is an error ("add return types or return nothing"). A value-returning function must return on every path.

declare.sol content_copy 
local function add(a : number, b : number) : number
    return a + b
end

function log(msg : string)          -- rets-less: returns nil
    print(msg)
    -- return 42                    -- error: add return types
end

Multiple returns

Return types are listed comma-separated — no parentheses. Callers unpack them as in Lua, and a function may tail-return another call's results, checked per position. Parenthesization truncates: (f()) yields exactly one value.

multi.sol content_copy 
local function head_and_count(xs : table[number]) : number?, number
    return xs[1], #xs
end

local first, total = head_and_count({ 7, 8, 9 })
local only = (head_and_count({ 7, 8, 9 }))  -- truncates to one

Varargs

The ellipsis must come last. Use select("#", ...) for the count — it is typed number — and select(n, ...) to spread unknowns. Using ... outside a varargs function is a compile error.

varargs.sol content_copy 
local function sum(...)
    local total = 0
    for _, value in ipairs({ ... }) do
        total = total + value
    end
    return total
end

print(sum(1, 2, 3)) -- 6

Closures, recursion, and local classes

Anonymous functions are fully checked, including at the call site — argument count and types are verified. local function may recurse: the name is pre-declared. Classes may be declared inside functions too, but a factory returning a body-local class cannot name the return type — declare shared classes outside the function or return through an interface.

closures.sol content_copy 
local scale = function(factor : number)
    return function(value : number) : number
        return value * factor
    end
end

local n : number = scale(2)(21) -- 42

Checked standard library

The standard library follows the any/unknown split: dynamic parameters are unknown — print(v : unknown), tonumber(v : unknown) — while untyped containers stay table[any]. tonumber returns number? because parsing can fail; tonumber and tostring are the conversion checkpoints of the whole language.

stdlib.sol content_copy 
local s : string = "abc"
local n : number = s:len()

local parsed : number? = tonumber("42")
local safe : number = parsed ?: 0
