Error Handling

Soleil inherits Lua's error model: raise with error, contain with pcall, and assert invariants with assert — all of it type-checked.

Raising errors

error aborts the current function and unwinds to the nearest protected call. The second argument sets the error position level.

raising.sol content_copy 
function withdraw(acct : table[string, number], amount : number) : number
    if (acct.balance ?: 0) &lt; amount then
        error("insufficient funds")
    end
    acct.balance = acct.balance - amount
    return acct.balance
end

Containing with pcall

pcall runs a function in protected mode and returns a success flag followed by the result or the error. The stdlib signature is checked, so the flag lands as a boolean.

pcall.sol content_copy 
local ok, err = pcall(function()
    error("something exploded")
end)

if not ok then
    print("caught: " .. tostring(err))
end

assert

assert raises when its first argument is false or nil, and passes the value through otherwise — the checked way to unwrap a nullable.

assert.sol content_copy 
local maybe_name : string? = nil

local name : string = assert(maybe_name, "name is required")
print(name:len())  -- guaranteed non-nil here

Patterns

  • Return number? / string? for expected failures that callers handle with ?: or if ~= nil.
  • Reserve error for bugs and broken invariants.
  • Wrap untyped Lua at module boundaries with pcall.
